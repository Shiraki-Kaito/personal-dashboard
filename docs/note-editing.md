# ノートの下書き保存

ノート本文を開き「編集用の下書きを作る」→編集→「下書きを保存」で、本人専用の既存Durable Objectへ保存します。自動保存ではありません。再読み込み・再起動後は「保存済みの下書きを開く」から復元します。

GitHubへは書き込まず、読み取り専用権限を維持します。本文はプレーンテキストとして扱い、ローカル限定の *_L.md は対象外です。コピー・Markdown保存も利用できます。

保存は20件まで、1件は本文・付随情報を合わせてUTF-8で100KiBまでです。容量超過・通信失敗・競合時は以前の保存内容を保持します。同じ版からの並行保存は一方を停止します。応答だけ失われた場合は同じ操作ID・同じ内容で結果を照合でき、無条件な重複作成はしません。入力を変えた再送で競合した場合はコピーして保存済み一覧を開き直してください。

元の接続範囲・パス・コミットを保存します。接続を停止・変更しても下書きは保持し、「以前の接続範囲」と表示します。復元はGitHub最新版との一致を意味しません。元のノートを読み直して比較する機能と、GitHubへの直接保存は未実装です。

「下書きのバックアップ・復元」で保存済み下書きを専用JSONとして書き出せます（通常のアプリバックアップとは別）。本文を含むため安全な場所へ保管してください。復元内容を確認してから不足分だけ追加し、同じIDで異なる内容がある場合は全体を停止します。復元は20件・各100KiBの制限を維持します。保存済み一覧の削除ボタンは対象名・保存日時を確認し、保存版が変わっていれば停止します。削除後の復元には専用JSONが必要です。Windows専用アプリではダウンロードが無効なので、通常ブラウザーまたはコピーを使います。保存ボタンを押す前の変更はサーバーに残りません。

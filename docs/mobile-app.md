# iPhone・iPadでの利用

既存の本人限定Webアプリをホーム画面から開く方式です。TestFlight版ではありません。

「接続と取得状況」→「端末にアプリとして追加」で端末に合った案内を表示します。Safariでサイトを開き、共有メニューから「ホーム画面に追加」を選びます。「Webアプリとして開く」がある場合は有効にします。詳細手順は折りたたみ欄から確認できます。

追加操作を案内しただけでは、インストール完了とは表示しません。独立起動はdisplay-modeとiOSのstandalone値で判定します。端末情報は案内にのみ使い、認証・認可には使いません。Mac形式の端末情報を返すiPadもタッチ対応情報を併用して案内します。

ホーム画面から開く際には本人ログインが必要になる場合があります。既存のAPI認可は維持します。インターネット接続が必要で、オフライン編集や秘密情報の新しい端末キャッシュは追加していません。新たな有料サービスも追加していません。

2026-11-21：全389テスト・ビルド合格。配信経路の追加後、本人認可を含む関連7テスト合格。iPhone／iPadの案内、Macとの区別、標準・iOS独立起動判定、追加済みと起動中の区別、未対応時の案内を模擬入力で確認しました。実端末での表示・OAuth復帰・ホーム画面起動は未確認です。本番デプロイ済みです（版：625ade14-2a85-47fe-ae59-14fad1208e7c）。

手順の根拠：[Apple公式・iPhoneでWebサイトをアプリにする](https://support.apple.com/en-az/guide/iphone/iphea86e5236/26/ios/26)。OSやブラウザーによりメニューの位置・表記は異なります。

# 脅威モデル（2026-11-26、日本時間）

対象：インターネット公開のCloudflare Workers＋SQLite Durable Object、同一originのJS画面、Windows .NET Framework＋WebView2。iOSはPWA案内だけ。本人1名のGitHub node IDをサーバーで照合。ソースはPublic、本番データは本人のみ。Slack・DevHubは引き続き保留。

資産：Google/GitHub接続資格情報、メール本文・予定、Driveメタデータ・メンバー名簿、ノート下書き、定例報告、本人による外部更新権限、Cloudflare利用量。DOはWorkerバインディング経由で、ブラウザーからDBへ直接接続しない。CIに本番秘密値を渡さず、デプロイは認証済みローカルWranglerから行う。

信頼境界：ブラウザー入力→Workerの認可/Origin/上限→単一DOの直列処理→検証済み操作→固定ホストの外部API→範囲・サイズ検証→保存→textContent中心の表示。外部文書/メールはコードとして実行しない。AI API・自動メール送信は存在しない。

攻撃者：未認証の外部アクセス、別GitHubユーザー、不正Origin、盗まれたCookie、悪意のある外部本文、サプライチェーン、管理アカウントの侵害。元資料の閲覧権があることとダッシュボードの本人認可は別に扱う。

P1：管理者フィッシング耐性MFA未確認、公開ソース/画像の実名、サイズ制限前のJSON読込、IdP失効後のセッション残留、ログイン試行/資源制限不足。実名以外の有効な秘密値漏えいや認可回避を今回確認したわけではない。

L3：決済・他者アカウントの管理サービスはない。ただし個人情報と外部操作権限があるため、管理者認証・緊急失効・バックアップ保護を重点対象とする。L3を一括適用・準拠認定はしない。

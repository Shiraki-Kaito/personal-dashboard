personal-dashboard プライバシーポリシー

更新日：2026年11月11日。本アプリは管理者本人専用の個人ダッシュボードです。第三者への利用提供は行いません。

取得する情報と利用目的

GitHubの本人識別情報でログインを認可し、設定済みGitHub Projectsのタスク情報を取得します。状態・期限は本人の明示操作で更新します。Google Driveは認可されたアカウントのメタデータ閲覧権限を使用し、設定したフォルダと通常のサブフォルダ内のファイル名・識別子・種類・保存場所・作成更新日時を取得します。Driveのファイル本文は取得しません。

取得情報は、一覧の表示、同期の照合、未同期操作の復旧、未確認変更の表示に使用します。AIの学習や広告に使用せず、第三者への販売は行いません。

保存と外部サービス

アプリはCloudflare WorkersとDurable Objectsで動作します。外部サービスのアクセストークン等の資格情報、取得したメタデータ、同期状態、未確認変更はサーバー側に保存します。秘密値をブラウザーへ配布しません。ブラウザーにはログイン用のSecure・HttpOnly Cookieを使用します。通信先はCloudflare、GitHub、Googleです。解析・広告用のトラッカーは導入していません。

保存期間と確認済み操作

直近の成功一覧は取得に失敗しても保持し、次の成功取得で更新します。未確認変更は本人が確認済みにするまで保持します。確認済み操作はアプリ内の未確認一覧だけを変更し、Driveのファイルを変更・削除しません。未同期のGitHub操作は照合完了または明示的な破棄まで保持します。操作記録の完全な履歴を保存するものではありません。

連携解除と削除

GitHubのログアウトでアプリのGitHubセッションと保存トークンを破棄します。Drive連携とキャッシュはログアウト後も保持します。GitHubとGoogleのアカウント設定で本アプリの認可を取り消せます。認可の取消は保存済みキャッシュを自動削除しません。保存データの完全な削除は管理者が本アプリ専用のサーバー保存領域で行います。再接続時にはDriveの取得済み一覧と未確認変更をリセットします。

Googleユーザーデータ

Google APIから受け取った情報の使用と他のアプリへの転送は、限定的使用の要件を含むGoogle API Services User Data Policyに従います。アプリの管理・連絡先は専用Google Cloudプロジェクトのユーザーサポート情報で管理します。

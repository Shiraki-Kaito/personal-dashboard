personal-dashboard プライバシーポリシー

更新日：2026年11月13日。本アプリは管理者本人専用の個人ダッシュボードです。第三者への利用提供は行いません。

取得する情報と利用目的

GitHubの本人識別情報でログインを認可し、設定済みGitHub Projectsのタスク情報を取得します。状態・期限は本人の明示操作で更新します。Google Driveは認可されたアカウントのメタデータ閲覧権限を使用し、設定したフォルダと通常のサブフォルダ内のファイル名・識別子・種類・保存場所・作成更新日時を取得します。Driveのファイル本文は取得しません。

取得情報は、一覧の表示、同期の照合、未同期操作の復旧、未確認変更の表示に使用します。AIの学習や広告に使用せず、第三者への販売は行いません。

メール・カレンダーは本人が追加認可した最大5アカウントについて、直近14日のメールを1回20件・最大100件取得します。毎時の自動取得は接続・ページごとに分割し、前の完全な一覧を最後まで保持してから更新します。就活・学校関係の語句で重要度を判定し、通常表示を絞りますが、判定対象の取得済みメールは全件一覧にも残します。表示名は40文字までアカウントとは別に保存します。件名・差出人・受信日時・本文を予定候補の抽出に使用し、抜粋と抽出結果を保存します。添付ファイルは取得しません。各アカウントのメインカレンダーから候補時間帯の予定を読み、重複・時間競合を照合します。また、毎時の自動取得と本人の「予定を更新」操作で今日を含む7日間の予定を取得し、予定名・日時・場所・識別子・元サービスへのリンクを一覧用に保存します。上限は各アカウント500件で、全ページを取得できなければ前の完全な一覧を保持して警告します。登録は本人が予定名・日時・場所・登録先を確認した場合だけ行います。メールの送信・削除・既読変更や招待は行いません。

メール取得履歴は各接続の直近72回について開始・完了時刻、取得元、件数、ページ数、結果・エラー分類を保存し、件名・本文・資格情報は履歴へ含めません。メールの取得一覧は次の正常な取得で置き換え、取得失敗時は保持します。予定の登録結果不明・成功の操作記録は復旧と二重登録防止のためサーバーに保持します。メール本文の全文を恒久保存せず、本文抜粋は1通1600文字までです。手動バックアップv2には取得済みメールの抜粋・候補・確認記録・予定登録記録・表示名・重要判定を含めます。資格情報・セッション・認可途中の状態・取得履歴・診断履歴・再取得できる直近予定一覧のキャッシュは含めません。バックアップには私的な情報が含まれるため、本人が安全に保管します。

Slack連携

本人が専用Slackアプリを認可した最大5ワークスペースについて、Botが参加し、サイトで追加した各最大5チャンネルを読み取ります。公開チャンネルはchannels:read・channels:history、非公開を選ぶ場合はgroups:read・groups:historyを使います。Slackへの投稿・招待・既読変更は行いません。DM・グループDMは初期対象外です。

直近7日の投稿を1ページ15件・最大10ページずつ毎時取得し、投稿本文（6000文字まで）・送信者ID・投稿時刻・返信件数・添付件数・元サービスのリンクを保存します。スレッド返信全文・添付本文・ユーザープロフィールは取得せず、AI処理・学習・広告用途にも使いません。取得上限やSlackプランによる履歴制限は表示します。確認済み操作はアプリ内だけの記録で、Slackの既読状態は変えません。

専用アプリのClient ID・Client Secret・接続トークンは、本人限定の設定APIからCloudflareのサーバー保存領域へ登録できます。秘密値は取得APIに含めず、再表示しません。接続停止は対象ワークスペースのトークンを破棄し、取得を止めます。チャンネル設定・投稿キャッシュ・確認記録は保持し、Slack側の認可取消とは区別します。次の取得成功で投稿キャッシュを更新し、失敗時は前回の一覧を保持します。アプリ内のSlack確認記録は次の確認操作で30日より古い分を整理します。現行の手動バックアップv2にはSlack情報は含まれません。

GitHub上のノート

本人がサイトで指定した1リポジトリ・対象フォルダ以下のMarkdownを読み取り専用で表示します。非公開の場合は本人が専用Fine-grained tokenを非表示欄から登録します。トークンはサーバー保存領域にのみ保持し、取得API・バックアップに返しません。公開の場合は認証情報を付けず取得します。GitHubのツリー応答には対象内のファイル名等が含まれますが、*_L.md（大文字小文字を区別しない）に該当するパスは一覧保存・ブラウザー送信から除外し、本文APIを呼び出しません。アーカイブ全体を取得しません。

ノートのパス・識別子・サイズと選択コミットを一覧として保存し、本文は本人が選択した時だけ読み、サーバーへ恒久保存しません。Markdown原文を表示し、埋め込み画像・HTML・スクリプトは読み込みません。本文に書かれたローカル限定ノートへの言及や転載内容まで自動判別するものではありません。更新は手動、取得失敗時は前回の一覧を保持します。接続削除は本アプリの設定・資格情報・一覧を削除しますが、GitHub上のファイルやトークンの認可そのものは削除しません。現行の手動バックアップにノート情報は含みません。

Windowsの独立ウィンドウ

Chrome／Edgeのアプリ追加機能を使い、同じ本人専用サイトを独立した通常ウィンドウで開けます。追加用の一般的なアプリ名・アイコン・表示設定だけを未ログインでも取得できます。データAPI・画面の実行用JavaScriptは本人認可を維持します。追加によって外部サービスの権限を増やしません。端末への独自の本文保存・オフライン編集・Service Workerによるキャッシュ・自動起動・通知権限は追加していません。インストールの操作はブラウザーが処理し、アプリ側にインストール済みフラグを永続保存しません。ブラウザー側の通常の履歴・アプリ管理情報はそのブラウザーの設定に従います。

保存と外部サービス

アプリはCloudflare WorkersとDurable Objectsで動作します。外部サービスのアクセストークン等の資格情報、取得したメタデータ、同期状態、未確認変更はサーバー側に保存します。秘密値をブラウザーへ配布しません。ブラウザーにはログイン用のSecure・HttpOnly Cookieを使用します。通信先はCloudflare、GitHub、Google、接続した場合のSlackです。解析・広告用のトラッカーは導入していません。

保存期間と確認済み操作

メールの「確認済み・対応不要」は、元メールのIDと確認時刻をアプリ内に保存します。Gmailの既読・ラベル・本文には変更を加えません。次の確認操作時に14日より古い確認記録を整理し、1アカウント5000件を上限とします。予定候補なしと判定したメールも取得済み全件一覧から確認できます。

直近の成功一覧は取得に失敗しても保持し、次の成功取得で更新します。未確認変更は本人が確認済みにするまで保持します。確認済み操作はアプリ内の未確認一覧だけを変更し、Driveのファイルを変更・削除しません。未同期のGitHub操作は照合完了または明示的な破棄まで保持します。操作記録の完全な履歴を保存するものではありません。

連携解除と削除

GitHubのログアウトでアプリのGitHubセッションと保存トークンを破棄します。Google連携とキャッシュはログアウト後も保持します。GitHubとGoogleのアカウント設定で本アプリの認可を取り消せます。認可の取消は保存済みキャッシュを自動削除しません。同じGoogle OAuthアプリへの認可取消は、そのGoogleアカウントの他の連携にも影響する場合があります。保存データの完全な削除は管理者が本アプリ専用のサーバー保存領域で行います。Driveの再接続は同一アカウントを照合して一覧と未確認変更を保持します。

Googleユーザーデータ

Google APIから受け取った情報の使用と他のアプリへの転送は、限定的使用の要件を含むGoogle API Services User Data Policyに従います。アプリの管理・連絡先は専用Google Cloudプロジェクトのユーザーサポート情報で管理します。
